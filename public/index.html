CRYPTOGRAPHIC ATTESTATION

Vault & Encryption Specifications

Details on how data objects and node keys are shielded inside SoTaNik_AI Data Lake.

AES-256-GCM Envelope Encryption
All node credentials and sensitive connection parameters are encrypted with an isolated 256-bit master key before touching Postgres storage.
Row-Level Security (RLS) Enforcement
Database rows are bound to tenant UUID (auth.uid() = user_id), ensuring zero cross-tenant row contamination.
Stateless JWT Authorization
API endpoints verify fresh signed bearer tokens on every transaction. No session state is leaked to disk.
